# 已安装管理器支持（1.1.0）

应用可以识别设备上已安装并启用的 KernelSU、SukiSU 或 ReSukiSU 管理器，并按用户选择使用对应版本。若只安装一个支持的管理器，会自动选择；存在多个时会显示选择项。未发现支持的管理器时，应用继续使用原有方式。

## 使用前

- 请确认设备与本应用适配范围一致：vivo X200 / x200_b57。
- 重启后按应用提示等待，再启动流程。
- 管理器及系统版本不同可能影响兼容性；此版本的实机测试范围有限。

## 检查结果

完成后请在所选管理器中确认状态，并使用平时可信的方式检查权限是否可用。

1.1.0 已知情况：首次完成后的最后检查可能等待较久并显示未通过，而实际功能已经可用；重新检查有时会通过。遇到这种情况，先查看管理器状态，不要仅凭这条提示重复执行完整流程。后续版本会改进检查时序和提示。
